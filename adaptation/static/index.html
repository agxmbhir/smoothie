About

This is a Monte Carlo Tree Search (MCTS) implementation for UI adaptation. The algorithm explores different UI states and optimizes for the best user experience.

How it works:

  • Selection: Traverse the tree to find the most promising node
  • Expansion: Add new child nodes to explore
  • Simulation: Run random playouts from the new node
  • Backpropagation: Update values back up the tree

Smoothie MCTS - Built with Rust & Actix-web
